UI-01 同根修复还覆盖仅修改端口名称时的意外重排及预览不一致。现在使用原有 `offset` 字段保留端点，显式调整排布、数量、顺序或间距才重排；节点与模板改名、保存刷新、SVG 路径及独立展示已通过三浏览器定向检查。

兼容边界：旧 JSON 若显式在节点 `data.ports` 中配置了 `offset`，却没有 `portSpacing`，旧版本忽略这些偏移，0.6.2 会按偏移绘制。这是本次保真修复的预期变化。由原界面保存、带 `portSpacing` 的等距自定义端口沿用原规则；没有增加文件字段或修改 Schema、宿主 API。

UI-07 修复前采用隔离浏览器路由加载原始版本展示页模块复现，操作入口为用户可见的文件选择按钮。曾在隐藏的发布页上传输入中发现同源残留，但该入口普通用户不可达，不另计缺陷。

新回归位于 `tests/browser/audit-{forms,canvas,library,interface}.spec.ts`。端口排布的前一批问题仍由 `port-distribution.spec.ts` 覆盖，不重复计入本次新发现。
