本项目将逐步完善为可正式使用的通用拓扑制作工具，并提供可嵌入业务软件的独立展示组件。优先保障工作成果可恢复、编辑操作高效、运行状态可信，再完善图面表达和平台能力。

本文件是持续维护的实施记录。每次开始工作先查看“当前工作”和步骤表，完成一个步骤后更新状态、验证结果和下一项任务；实现范围发生变化时先修改本文件。

## 工作规则

1. 按步骤推进，优先修复阻碍当前步骤的问题。保留人工布局和手工走线，自动整理提供可撤销的操作。
2. 每项工作明确范围、验收标准、测试结果和遗留项。状态使用“待开始、进行中、待验收、已完成”。
3. “已完成”表示实现和该步骤必需验证均通过。代码已实现而浏览器验收受限时记录“待验收”，不将用例列举或构建成功视为浏览器通过。
4. 因环境限制无法完成的检查须保留准确报错、复现命令及重新验收方法。其他独立工作可继续，相关发布验收保持待办。
5. 新增依赖统一使用 `bun install`。修改文件格式时同步维护 Schema、迁移逻辑、导出及独立展示组件。
6. 每步完成实现后运行相关测试和构建；有新失败或实质变更时再追加检查。涉及交互时运行对应浏览器用例。
7. 更新 README 和接入说明中受到影响的行为；维护本文件中的状态、检查清单及迭代记录。
8. 完成一个可预览的批次后执行 `bun run deploy`。区分构建成功、上传成功和页面验收，不将预览部署等同于正式发布。
9. 版本提交和推送按用户指令执行，不自动提交未审核的改动。

## S04 对齐、分布、位置锁定和右键菜单

### 本批次范围与规则

- 六种对齐：左、水平中心、右、顶、垂直中心、底。无锁定节点时以选区边界为基准；存在锁定节点时以选择顺序中的首个锁定节点为参照。
- 水平/垂直等距分布按实际节点尺寸计算空隙，固定两端位置，至少需要三个未锁定节点；空间不足时提示，不制造负间距。
- 指定间距分布至少需要两个未锁定节点，固定首个节点，间距为 0–10000 px，另一坐标轴保持原位。锁定节点不参与分布。
- 位置锁定作为可选 `data.locked` 布尔字段保存，缺省为未锁定。锁定节点仍可选择、连接和编辑参数，拖动、方向键、对齐、分布及节点批量删除会跳过它。
- 显式删除选中的连线，或删除关联的未锁定节点时，允许移除连接锁定节点的线；副本默认解锁，仍使用新的设备 ID 和绑定源。
- 锁定标记仅用于编辑界面，不出现在 PNG、SVG、独立展示或 HTML 的查看效果中；文件和组件继续保留锁定字段。
- 对齐/分布时，连线两端若发生相同位移，其拐点整体平移；不同位移或仅一端移动时保留原手工拐点。所有命令先校验后执行，每次可一步撤销。
- 编辑模式提供节点、连线和空白处的右键菜单，已选对象上右键保留多选。菜单支持常用编辑、锁定、对齐/分布；查看模式只提供查看/导出操作。右键粘贴以点击位置放置节点组。
- 不增加依赖；同步通用格式解析、Schema、草稿历史、导出、组件类型和接入说明。

## S06 分组、注释和图面表达

### 本批次范围与规则
