# Topology · 拓扑制作工作台

基于 AntV X6、TypeScript 和 Vite，包含通用拓扑文档、多个拓扑的制作与管理，以及可在其他软件中嵌入的独立展示组件。支持地面站、机房网络、卫星逻辑结构和自定义场景。

## 启动

```bash
bun install
bun run dev
```

默认本机地址为 `http://127.0.0.1:5173`。开发和预览均监听 `0.0.0.0`；其他设备可访问终端显示的 Network 地址。端口以实际输出为准，修改启动配置后需重启服务。

## 部署到预览服务器

```bash
bun run deploy
```

脚本自动构建，将 `dist/` 上传到 `ubuntu@101.43.68.117` 的 `/home/ubuntu/station-device-draw/dist/`，并通过 Python 3 在 `0.0.0.0:10001` 提供静态预览。访问 http://101.43.68.117:10001，独立展示页为 http://101.43.68.117:10001/viewer.html。

本机需要 Bun、SSH、SCP，并能通过 SSH 登录该服务器；服务器需要 Python 3，安全组和防火墙需放行 TCP 10001。后续修改后再次执行同一命令即可，服务在 SSH 断开后继续运行；服务器重启后需重新执行脚本。日志位于服务器 `/home/ubuntu/station-device-draw/preview.log`。

部署仅更新静态页面；拓扑文档仍保存在访问者浏览器中，不同访问地址之间请通过 JSON 导入导出迁移。

## 本次交付

- **通用文件 v2**：文档元数据、节点模板、参数定义、数据绑定、连接点、节点位置、手工走线和线缆外观共同保存到 `.topology.json`。
- **拓扑库**：新建、打开、复制、修改名称/分类/说明、删除；切换前自动保存当前图。每张图的编辑历史在当前会话中独立保存。
- **独立展示组件**：构建为 ES module、UMD 和 TypeScript 声明；接收文件及宿主数据，支持节点点击回调、缩放和生命周期清理。
- **独立预览页**：`/viewer.html`，可导入文件并手动发送数据；不包含编辑界面和自动模拟器。
- **自定义节点模板**：名称、内置图标、最多 20 项参数以及四边连接点；模板随文件携带，不再限于固定设备类型。
- **图片与网页导出**：PNG、纯矢量 SVG、内嵌展示组件和数据快照的单文件 HTML，可离线打开。

## 推荐验证流程

1. 打开“拓扑库”，新建“运控中心机房”或“卫星逻辑结构”示例；也可以选择通用空白图。
2. 在“拓扑编辑”拖入节点，手动调整位置。从同类型连接点拖线，点击连线调整拐点或线段。
3. 用“新建节点模板”创建其他业务节点。参数定义每行填写 `标识,名称,单位,小数位数`，例如 `voltage,电压,V,2`。
4. 点击节点修改名称、业务 ID、展示参数；展开“数据绑定”，配置业务对象 ID、参数路径和状态映射，点击“应用修改”。
5. 新建或切换另一张图，再切回来，确认原图布局保留；拓扑库支持复制、修改信息和删除，最后一张不能删除。
6. 保存后导出 `.topology.json`。点击“独立预览”，或在 `/viewer.html` 中导入该文件。
7. 独立预览初始显示“等待数据”。右侧点击“填入示例数据”，再点击“更新数据”，验证动态值、状态及节点点击回调。

编辑器中的“模拟实时”每两秒生成数据，仅用于制作时验证效果。独立展示组件由宿主提供数据，不启动模拟器，也不直接连接采集服务。

## 布局与线缆

- 默认连接点由模板定义。通用逻辑节点默认上下左右四个点，同一点可以承接多条连接。
- 点击设备的“配置端口 / 批量新增”可增减连接点、按边分组、排序、设置间距，或补齐 24 / 48 口。每台最多 128 个；默认最小间距 24 px，超过容量时只扩展当前节点，不移动周边设备。
- 已连接端口可改名和调整位置，不能直接删除或改变类型；需要删除时先解除连线。应用配置保留端口 ID、连线和手动拐点。
- 首页监控、独立展示隐藏端口圆点与编辑手柄。端口名称在编辑时悬停查看，长列表在详情中折叠。
- 节点卡片随展示参数收紧：不选参数时移除参数区，单项参数横向展示，两项参数并排展示。连接点跟随节点尺寸变化；端口较密集时仍保留必要的间距。
- 连线支持实线、虚线、双线、护套与编织纹理，可设置 1–14 px 粗细、颜色和方向箭头。离线时变灰、分段，恢复后还原外观。
- 大量连接可按业务方向分边，结合类型筛选和选中高亮。需要时可创建多张按机柜、业务或子系统划分的图。

## 文件格式与旧数据

格式说明与接入示例见 [独立组件接入](docs/integration.md)，结构定义见 [JSON Schema](schema/topology-v2.schema.json)。

- 新格式为 `format: "topology-document"`、`version: 2`，每份文件自带所需模板。
- 导入始终新增文档；若文档 ID 已存在，则生成新的文档 ID，保留原图。节点 ID 作用域在各文档内。
- 原单图 v1 文件可继续导入。浏览器旧键 `station-x6-topology-v1` 首次自动迁移到新库，旧键原样保留。
- 新库键为 `topology-workspace-v1`。存储失败不会切换图或覆盖上次成功保存的库，当前画布仍可导出备份。
- 不同浏览器、访问地址或端口拥有各自存档；JSON 文件可用于迁移。损坏的库不会被启动流程静默覆盖。
- 当前约束：每个库最多 100 张图，每份文档最多 64 个模板、300 个节点、1000 条线；单次导入文件最大 3 MB。浏览器实际可保存容量受 localStorage 配额影响。
- 校验覆盖文件版本、模板、参数、端口类型、绑定和坐标。不执行导入文件中的 HTML、脚本或表达式。

## 构建与接入其他软件

```bash
bun run build
```

生成两个产物：

- `dist/`：制作工具和独立预览页，可使用 `bun run preview` 查看，默认端口 `4173`。
- `dist-viewer/`：可单独复制、安装的展示包，包含 ES module、UMD、类型声明与 JSON Schema，不需要部署完整制作工具。

仅构建展示包可以执行 `bun run build:viewer`。宿主以 `new TopologyViewer(container, { definition })` 加载图，用 `setData()` / `updateData()` 传入实时值。JavaScript、React 客户端包装及 UMD 用法见 [接入文档](docs/integration.md)。容器需设置明确高度。

## 导出图片与独立网页

点击画布右上角的下载图标“导出拓扑”，选择 JSON、PNG、SVG 或 HTML。包含当前尚未保存的修改，导出不会修改本地存档。

- **JSON**：保留文档、模板、数据绑定和布局，可重新导入继续编辑。
- **PNG**：导出整张拓扑的参数、状态快照，默认 2 倍分辨率；超大图自动降低倍率，限制最长边 16384 px、总像素 3200 万，避免画布内存溢出。
- **SVG**：节点、文字、图标和线缆均为矢量，不含 `foreignObject`、位图或外部资源；文字使用本机字体。适合缩放、打印和文档排版。
- **HTML**：导出单个 `.html` 文件，内嵌拓扑、展示组件、样式和初始数据，双击即可离线查看，支持缩放、平移和节点点击事件，也可通过 iframe 嵌入软件。

图片导出覆盖完整拓扑和手动拐点，不受当前缩放、视口、链路筛选或选中状态影响；隐藏连接点和编辑手柄。无参数节点保持紧凑布局。空图可导出 JSON/HTML，图片导出需至少一个节点。

HTML 默认展示导出时的模拟数据快照，没有自动采集或刷新计时器。宿主通过导出页面的 `window.topologyViewer.setData(data)` / `updateData(patch)` 更新数据，按文档中的业务对象 ID、字段绑定提供数据。完整示例见 [HTML 接入说明](docs/integration.md#独立-html-文件)。

`bun run dev` 和 `bun run build` 会先生成独立展示包，用于 HTML 导出。展示组件源码修改后需重启开发服务，以刷新导出时内嵌的运行时。

## 验证

```bash
bun run test
bun run build
bun run test:e2e
```

数据测试覆盖保存恢复、文件迁移、多图隔离、模板和数据绑定、动态端口、手工走线及非法输入。Playwright 脚本覆盖原编辑交互、多图操作、自定义模板、独立组件数据更新、实例隔离与销毁。默认使用本机 Chrome，也可配置已安装的 `PLAYWRIGHT_CHANNEL=chromium`。

当前受限执行环境可以构建并运行数据测试，但本地监听和浏览器进程受限，浏览器测试需在本机终端运行；列举测试不代表浏览器执行通过。

## 代码结构

- `src/document.ts`：通用文档、模板、版本迁移和场景示例。
- `src/library.ts`：多图存储、校验、复制与删除。
- `src/rendering.ts`：编辑器与组件共用的节点、端口、线缆渲染。
- `src/viewer.ts`、`src/runtime-data.ts`：独立展示组件及宿主字段映射。
- `src/main.ts`：制作工作台、模拟监控与拓扑库界面。
- `src/topology.ts`、`src/port-editor.ts`、`src/cables.ts`：图模型、端口编辑和线缆外观。
- `src/viewer-demo.ts`：独立展示验证页；`src/viewer-index.ts`：组件包入口。
- `src/exports.ts`、`src/export-svg.ts`、`src/export-html.ts`：文件下载、PNG 栅格化、矢量拓扑和离线 HTML 打包。
- `schema/`、`docs/`、`tests/`：格式定义、接入文档和验证。

本次没有接入后端存储、权限或多人协作。独立网页以单文件 HTML 交付，无需额外解压资源包。
