# Topology · 拓扑制作工作台

基于 AntV X6、TypeScript 和 Vite，包含通用拓扑文档、多个拓扑的制作与管理，以及可在其他软件中嵌入的独立展示组件。支持地面站、机房网络、卫星逻辑结构和自定义场景。

后续推进顺序、验收标准和实施状态统一维护在 [迭代工作指引](docs/迭代工作指引.md)。每完成一个步骤更新该文件，作为持续开发的工作入口。

## 启动

```bash
bun install
bun run dev
```

默认本机地址为 `http://127.0.0.1:5173`。开发和预览均监听 `0.0.0.0`；其他设备可访问终端显示的 Network 地址。端口以实际输出为准，修改启动配置后需重启服务。

## 部署到预览服务器

```bash
bun run deploy
```

脚本自动构建，将 `dist/` 上传到 `ubuntu@101.43.68.117` 的 `/home/ubuntu/station-device-draw/dist/`，并通过 Python 3 在 `0.0.0.0:10001` 提供静态预览。访问 http://101.43.68.117:10001，独立展示页为 http://101.43.68.117:10001/viewer.html。

本机需要 Bun、git、tar、SSH/SCP，并能登录服务器；远端需要 Python 3、systemd、flock 和 ubuntu 免交互 sudo，安全组和防火墙放行 TCP 10001。后续继续执行同一命令；服务由 systemd 托管，异常自动重启，并配置开机恢复。`bun run deploy:status` 查看状态，`bun run deploy:rollback` 切换上一版；日志用 `journalctl -u station-device-draw -n 100 --no-pager` 查看，详见 [部署维护](docs/engineering.md)。

部署仅更新静态页面；拓扑文档仍保存在访问者浏览器中，不同访问地址之间请通过 JSON 导入导出迁移。

## 本次交付

- **通用文件 v3**：文档元数据、节点模板、参数定义、数据绑定、连接点、节点位置、手工走线和线缆外观共同保存到 `.topology.json`。
- **拓扑库**：新建、打开、复制、修改名称/分类/说明、删除；支持搜索、分类筛选、排序及有效草稿缩略图。每张图的撤销历史在当前会话中独立保存。
- **草稿与历史**：编辑停止约 1.25 秒后自动保留草稿，刷新及切图恢复；手动保存建立历史版本，恢复前备份当前内容，恢复操作可撤销。
- **多选与复制粘贴**：框选、组合键点选、整组移动、批量删除；复制节点及内部连线，可跨拓扑粘贴并自动携带模板，每次批量操作可一步撤销。
- **对齐、分布与锁定**：六种对齐、自动等距和指定间距，按节点实际尺寸计算；位置锁定支持保存、恢复及撤销，右键菜单提供常用操作。
- **分组与图面表达**：区域分组、成员管理、整组移动与复制、文字注释、链路图例、尺寸手柄及置顶/置底，支持保存、撤销、展示和导出。
- **工具布局**：紧凑状态栏、侧栏折叠与调宽记忆、可折叠属性分区和就地表单校验，窄屏可通过节点库抽屉添加节点。
- **独立展示组件**：构建为 ES module、UMD 和 TypeScript 声明；接收文件及宿主数据，支持节点点击回调、缩放和生命周期清理。
- **独立预览页**：`/viewer.html`，可导入文件并手动发送数据；不包含编辑界面和自动模拟器。
- **自定义节点模板**：名称、内置图标、最多 20 项参数以及四边连接点；模板随文件携带，不再限于固定设备类型。
- **图片与网页导出**：PNG、纯矢量 SVG、内嵌展示组件和数据快照的单文件 HTML，可离线打开。

## 推荐验证流程

1. 打开“拓扑库”，新建“运控中心机房”或“卫星逻辑结构”示例；也可以选择通用空白图。
2. 在“拓扑编辑”拖入节点，手动调整位置。从同类型连接点拖线，点击连线调整拐点或线段。
3. 用“新建节点模板”创建其他业务节点。参数定义每行填写 `标识,名称,单位,小数位数`，例如 `voltage,电压,V,2`。
4. 点击节点修改名称、业务 ID、展示参数；展开“数据绑定”，配置业务对象 ID、参数路径和状态映射，点击“应用修改”。
5. 新建或切换另一张图，再切回来，确认原图布局保留；拓扑库支持复制、修改信息和删除，最后一张不能删除。
6. 保存后导出 `.topology.json`。点击“独立预览”，或在 `/viewer.html` 中导入该文件。
7. 独立预览初始显示“等待数据”。右侧点击“填入示例数据”，再点击“更新数据”，验证动态值、状态及节点点击回调。

编辑器中的“模拟实时”每两秒生成数据，仅用于制作时验证效果。独立展示组件由宿主提供数据，不启动模拟器，也不直接连接采集服务。

画布工具栏可以切换“模拟数据 / 宿主数据”。编辑器收到 `window.stationPrototype.updateTelemetry(deviceId, metrics, status)` 的有效设备更新后自动进入宿主模式，模拟器停止；未收到数据的节点显示“等待数据”，缺失参数显示 `—`。通过工具栏主动切回模拟模式后恢复采样。数据模式与运行值不写入拓扑文件。

## 工作区与拓扑库

顶部左侧按钮收起/展开节点库；画布右上角按钮收起/展开属性栏。桌面可拖动分隔线调宽，聚焦分隔线后用方向键调整 10 px、Shift + 方向键调整 40 px，Home/End 到最小/最大宽度，双击恢复默认。折叠节点库后仍可使用图标添加节点。窄屏通过同一按钮打开抽屉，点击模板添加节点后自动关闭，Esc 或遮罩也可关闭。

节点属性按基本信息、卡片参数、连接端口及数据绑定分区展开；“应用修改”在面板底部固定显示。校验失败会展开错误所属分区、聚焦字段并保留已输入内容，成功应用后才修改画布。未应用的表单输入不属于自动草稿。

拓扑库可搜索名称、说明及分类，支持分类筛选和按最近修改/名称排序。缩略图展示当前有效草稿的节点位置、连接及手工拐点，点击缩略图可打开拓扑；搜索与排序不修改拓扑。草稿标记表示尚有草稿存档。

侧栏尺寸、折叠状态及属性分区开关保存在独立的 `topology-workbench-ui-v1` 本地键中，不进入通用文件、草稿、历史或运行值。偏好损坏时使用默认布局，偏好保存失败不影响制图存档；缩略图按需生成，不保存截图或运行参数。拓扑库搜索条件在当前会话内保留。

## 设备状态与工作台配色

工作台使用蓝灰主题，画布中的节点类型、连接类型及图面元素保留自己的颜色。告警弹窗、侧栏/顶栏告警入口、异常计数入口和底部模拟数据说明已移除；当前数据模式在工具栏选择。

节点在原有卡片尺寸内使用状态色条、边框、图标和文字共同区分：正常为绿色勾选，告警为琥珀色提示，离线为灰色虚线与断连标记，等待数据为蓝色点线与时钟。编辑器属性栏的“初始状态”可设置正常/告警/离线；接入宿主数据后，实际状态以宿主更新为准。

等待是未收到宿主数据时的显示状态，不新增文件状态枚举，也不会触发模拟数据。状态动态更新不修改节点位置、手工拐点、文档或撤销历史，编辑中的未应用字段保持原输入。独立展示及 SVG/PNG/HTML 导出共享状态样式，工作台主题不会进入导出图片。

## 自动保存与历史恢复

编辑停止后，顶部显示“草稿已自动保存”和保存时间。刷新或切换拓扑会自动恢复有效草稿；“保存布局”单独更新手动保存版本。未点击“应用修改”的属性表单仍是表单输入，不属于画布草稿。

点击画布右上角的时钟图标“草稿与历史”，可以恢复自动草稿、手动保存版本或历史检查点。恢复前先备份当前内容，恢复结果作为草稿载入，可一步撤销，确认后再手动保存。节点、模板、端口及手工走线一起恢复。

- 历史每图最多 10 个，全库最多 40 个，快照总量约 1.5 MB，优先保留较新的版本。连续修改约每分钟保留一个较早草稿检查点，手动保存和恢复前也建立版本。
- 超出历史容量的快照不进入历史；恢复前若无法保留当前内容，则拒绝恢复并提示先导出备份。当前草稿不会为腾出历史空间而删除。
- 保存失败时画布继续保留修改，显示错误，可重试或导出当前图。损坏的库不会被临时空图自动覆盖。
- 检测到其他标签页改写同一个拓扑库时暂停保存，导出当前图后可选择“重新读取”。此检测用于本地编辑保护，不提供多人并发事务保证。
- 删除拓扑会在同一次写入中清理所属草稿和历史；复制使用当前有效内容，副本拥有新的文档 ID。JSON/PNG/SVG/HTML 导出均使用当前画布内容，JSON 不携带本地历史。

制作工具的“独立预览”包含当前有效草稿；直接打开 `/viewer.html?document=文档ID` 读取手动保存版本。自动草稿不会替换后者。

## 查找与导航

图内搜索支持节点名称、业务/绑定 ID、地址、模板、链路名称及图面文字。制作工具中按 `/` 聚焦搜索，方向键和 Enter 选择结果；“关联”聚焦一跳连接，“清除”恢复。定位与聚焦仅改变视图，保留节点、拐点及撤销历史。

左下角小地图可点击、拖动或用方向键移动视口，随缩放、平移和编辑更新；“小图”按钮折叠。画布高度不足 240 px 时自动收起。独立组件和 HTML 同样支持搜索和小地图，可通过选项关闭。

编辑节点的“子拓扑”表单，关联库内其他图；查看节点时点击“打开子拓扑”。制作工具提供“返回”并恢复父图缩放、平移和选择，最多记忆 20 级。普通独立预览按草稿/保存来源进入，发布预览只进入已发布子图；缺失引用会提示并保留父图。

`childTopologyId` 是 v3 的可选字段，复制/保存/发布和导出均保留。子拓扑功能需要配套使用 0.6.0 制作工具和组件，旧版本可能忽略该字段。PNG/SVG 标记含子图的节点；HTML 通过 `topology:navigate` 事件将目标 ID 交给宿主，不自行读取其他软件的数据。

组件新增 `search()`、`focus()`、`navigateToChild()` 和 `onNavigate`，见 [接入说明](docs/integration.md)。`bun run test:benchmark` 独立顺序测量 100 节点/300 链路与 300 节点/1000 链路的加载、拖动、刷新；运行结果保存在 `performance-results/`；已测环境、口径和结果见 [S10 性能记录](docs/benchmarks/S10-performance.md)。

## 发布与版本

点击画布顶部“发布”，填写说明并“发布当前草稿”，才会更新正式展示配置；自动草稿和“保存布局”继续独立。旧库初始为未发布。发布记录保留版本号、时间、说明和配置快照，不包含实时参数、接收时间或连接状态。

“打开当前发布”进入 `/viewer.html?published=文档ID`，同一浏览器的展示标签页在发布/回滚后切换，草稿保存不影响它。“查看此版”使用固定历史版本链接；“回滚到此版”创建一个新版本并记录来源，保留草稿和编辑撤销历史。发布源图被删除后，跟随展示页清除旧图并显示不可用。

发布历史每图最多 10 版、全库最多 200 版且约 2 MB，优先保护各图当前发布；存储失败或版本冲突不改变原发布，可保留说明重试。“导出发布配置”生成对应版本的普通 v3 JSON，独立于当前草稿，重新导入后为未发布的新图。

发布存储属于当前浏览器，部署工具更新不会同步用户的拓扑库。跨设备发布由宿主实现 `PublicationRepository`，获取发布快照后传给展示组件，详见 [接入说明](docs/integration.md)。内部草稿元数据升级为版本 2，兼容读取旧版，旧工具会拒绝写入新存档以保护发布记录；通用拓扑文件仍为 v3。

## 布局与线缆

- 默认连接点由模板定义。通用逻辑节点默认上下左右四个点，同一点可以承接多条连接。
- 点击设备的“配置端口 / 批量新增”可增减连接点、按边分组、排序、设置间距，或补齐 24 / 48 口。每台最多 128 个；默认最小间距 24 px，超过容量时只扩展当前节点，不移动周边设备。
- 已连接端口可改名和调整位置，不能直接删除或改变类型；需要删除时先解除连线。应用配置保留端口 ID、连线和手动拐点。
- 查看模式、独立展示隐藏端口圆点与编辑手柄。端口名称在编辑时悬停查看，长列表在详情中折叠。
- 节点卡片随展示参数收紧：不选参数时移除参数区，单项参数横向展示，两项参数并排展示。连接点跟随节点尺寸变化；端口较密集时仍保留必要的间距。
- 连线支持实线、虚线、双线、护套与编织纹理，可设置 1–14 px 粗细、颜色和方向箭头。离线时变灰、分段，恢复后还原外观。
- 大量连接可按业务方向分边，结合类型筛选和选中高亮。需要时可创建多张按机柜、业务或子系统划分的图。

## 多选与复制粘贴

编辑模式的操作栏提供“框选 / 平移”工具。框选工具下拖动空白区域选择节点；平移工具下拖动空白区域移动视图，按住 Shift 拖动仍可框选。也可用 Ctrl、⌘ 或 Shift 点选增减选择，中键平移画布。

| 操作 | 快捷键或入口 |
| --- | --- |
| 全选节点 | Ctrl / ⌘ A |
| 复制 / 粘贴 | Ctrl / ⌘ C / V 或操作栏按钮 |
| 创建偏移副本 | Ctrl / ⌘ D |
| 移动所选节点 | 拖动任一已选节点，或方向键移动 10 px；Shift + 方向键移动 50 px |
| 删除所选对象及关联线 | Delete / Backspace |
| 取消选择 | Esc |

复制包含节点、所需模板、参数与端口配置，以及所选节点之间的内部连线。粘贴时整体偏移，重新生成节点、连线及设备业务 ID；数据绑定源改为新设备 ID，副本默认解锁，其余配置保留，请确认副本的管理地址与绑定。目标图的同名模板定义不一致时生成新模板别名，不覆盖目标模板。

整组移动时内部连线的手工拐点随组平移，对外连线的拐点保持原位、端点跟随节点。一次拖动、粘贴、方向键移动或批量删除分别作为一次可撤销操作。选择和剪贴板不保存到拓扑文件，实时参数也不会复制。

当前使用工作台内剪贴板，支持切换拓扑后粘贴，刷新页面后清空；文本输入框保持系统复制粘贴快捷键。查看模式禁止粘贴及批量编辑。粘贴前校验节点、连线、模板和坐标上限，超限时整次操作不生效。

## 对齐、分布与位置锁定

编辑操作栏的“对齐”提供左、水平中心、右、顶、垂直中心和底对齐。选择至少两个节点后可用；存在锁定节点时，以选择顺序中的首个锁定节点为参照，其他锁定节点保持原位。没有锁定节点时以选区的整体边界为基准。

“分布”只处理未锁定节点，按节点实际宽高计算空隙：

- 水平/垂直等距需要至少三个未锁定节点，两端固定，只整理中间节点。现有空间不足时提示使用指定间距。
- 指定间距需要至少两个未锁定节点，输入 0–10000 px（可含小数），固定排序后的第一个节点，另一坐标轴保持不变。

锁形按钮和单节点属性栏可以锁定/解锁位置。锁定节点仍可选择、连线和编辑参数；拖动、方向键、对齐、分布及节点批量删除会跳过它，并显示锁定数量或提示。显式删除选中的连线，或删除其另一端的未锁定节点，仍会移除对应连线。

对齐或分布中，若连线两端发生相同位移，拐点整体平移；不同位移或只有一端移动时保留原拐点，仅让端点跟随节点。每次对齐、分布、锁定及解锁均可一步撤销，越界会拒绝整次操作。

右键节点或连线打开编辑菜单，已选对象上右键保留多选；空白处菜单可以粘贴到点击位置。菜单支持方向键、Home/End、Enter 和 Esc，Shift+F10 可从画布打开菜单。查看模式只提供适应画布和导出。

锁定状态保存在可选 `data.locked` 布尔字段中，旧文档缺省为未锁定。锁定标记只在制作工具的编辑模式出现，PNG/SVG、独立展示及导出的 HTML 隐藏标记。

## 区域分组、注释与图例

编辑工具栏与右键菜单可创建分组、注释和图例。多选节点后点“分组”，会按当前节点边界创建区域，保留原节点位置；没有选中节点时创建空区域。

- 拖动区域标题或使用方向键会带走成员及内部连线拐点，对外拐点保持原位。拖动成员本身仍只移动该成员，成员关系不会因节点越出边框而自动改变。
- 区域属性中勾选成员，或在节点“所属区域”中调整归属；不支持嵌套分组。已有其他归属的节点须先移出原组。
- 拖动尺寸手柄或填写宽高只改变边框；“按成员适应边界”重新包围成员，仍不移动节点。任一成员单独锁定时阻止整组移动；锁定区域后，区域与成员都跳过位置整理及批量删除。
- “解散分组”或删除区域只移除容器，成员和连接保留；删除普通节点会同步清理成员引用。复制区域会复制成员、内部连线和所需模板，副本生成新 ID 且默认解锁。
- 注释使用纯文本，支持多行、颜色与字号。较长内容按宽高换行并省略，悬停可查看全文，调大尺寸可显示更多内容。图例按链路类型显示首条链路外观，可关闭状态图例。
- “层次”菜单和右键的置顶/置底调整重叠顺序。区域保持在连线下方，节点、注释、图例之间可调整前后关系。

图面操作均可一步撤销。查看模式和独立展示隐藏编辑手柄，图面元素不计入业务节点数及参数采样。只包含注释的图也可导出 PNG、SVG 和离线 HTML。

文件升级为 Topology v3；旧 v1/v2 可导入，新文件需使用支持 v3 的制作工具和 `0.6.1` 展示组件。旧版 Schema 保留在 `schema/topology-v2.schema.json`，不可仅降低版本号来使用新文件。

## 文件格式与旧数据

格式说明与接入示例见 [独立组件接入](docs/integration.md)，结构定义见 [JSON Schema](schema/topology-v3.schema.json)。

- 新格式为 `format: "topology-document"`、`version: 3`，每份文件自带所需模板及图面元素。
- 导入始终新增文档；若文档 ID 已存在，则生成新的文档 ID，保留原图。节点 ID 作用域在各文档内。
- 原单图 v1 和通用 v2 文件可继续导入并迁移到 v3。浏览器旧键 `station-x6-topology-v1` 首次自动迁移到新库，旧键原样保留。
- 新库键为 `topology-workspace-v1`。存储失败不会切换图或覆盖上次成功保存的库，当前画布仍可导出备份。
- 不同浏览器、访问地址或端口拥有各自存档；JSON 文件可用于迁移。损坏的库不会被启动流程静默覆盖。
- 当前约束：每个库最多 100 张图，每份文档最多 64 个模板、300 个节点、1000 条线及 100 个图面元素；单次导入文件最大 3 MB。浏览器实际可保存容量受 localStorage 配额影响。
- 校验覆盖文件版本、模板、参数、端口类型、绑定和坐标。不执行导入文件中的 HTML、脚本或表达式。

## 构建与接入其他软件

```bash
bun run build
```

生成两个产物：

- `dist/`：制作工具和独立预览页，可使用 `bun run preview` 查看，默认端口 `4173`。
- `dist-viewer/`：可单独复制、安装的展示包，包含 ES module、UMD、类型声明与 JSON Schema，不需要部署完整制作工具。

仅构建展示包可以执行 `bun run build:viewer`。宿主以 `new TopologyViewer(container, { definition })` 加载图，用 `setData()` / `updateData()` 传入实时值。JavaScript、React 客户端包装及 UMD 用法见 [接入文档](docs/integration.md)。容器需设置明确高度。

## 导出图片与独立网页

点击画布右上角的下载图标“导出拓扑”，选择 JSON、PNG、SVG 或 HTML。包含当前尚未保存的修改，导出不会修改本地存档。

- **JSON**：保留文档、模板、数据绑定和布局，可重新导入继续编辑。
- **PNG**：导出整张拓扑的参数、状态快照，默认 2 倍分辨率；超大图自动降低倍率，限制最长边 16384 px、总像素 3200 万，避免画布内存溢出。
- **SVG**：节点、文字、图标和线缆均为矢量，不含 `foreignObject`、位图或外部资源；文字使用本机字体。适合缩放、打印和文档排版。
- **HTML**：导出单个 `.html` 文件，内嵌拓扑、展示组件、样式和初始数据，双击即可离线查看，支持缩放、平移和节点点击事件，也可通过 iframe 嵌入软件。

图片导出覆盖完整拓扑和手动拐点，不受当前缩放、视口、链路筛选或选中状态影响；隐藏连接点和编辑手柄。无参数节点保持紧凑布局。空图可导出 JSON/HTML，图片导出需至少一个节点。

HTML 默认展示导出时的模拟数据快照，没有自动采集或刷新计时器。宿主通过导出页面的 `window.topologyViewer.setData(data)` / `updateData(patch)` 更新数据，按文档中的业务对象 ID、字段绑定提供数据。完整示例见 [HTML 接入说明](docs/integration.md#独立-html-文件)。

`bun run dev` 和 `bun run build` 会先生成独立展示包，用于 HTML 导出。展示组件源码修改后需重启开发服务，以刷新导出时内嵌的运行时。

## 数据新鲜度

宿主数据默认 15 秒未更新即过期。节点参数显示 `—`，链路变为未知并停止流转；过期、数据连接中断和设备真实离线分别显示。节点与链路分别计时，局部更新只延长对应对象的有效期，重连后需收到新数据才恢复。

制作工具工具栏的“数据接入设置”可调整超时或通知连接中断；节点/链路详情显示接收时间。独立组件支持 `freshness: { staleAfterMs: 15000 }`、`configureFreshness()`、`setConnectionState()` 和 `getDataStatus()`。超时设为 0 可明确关闭；设置及接收时间均不进入拓扑文件或撤销历史。宿主仍负责实际采集及连接管理。

HTML 初始快照冻结导出时的有效状态，收到首次宿主更新后转入实时超时逻辑。接入示例及快照模式见 [组件接入说明](docs/integration.md)。

## 模板与数据绑定

编辑模式可新建节点模板，通过行表单配置参数标识、名称、单位及小数位，在“模板连接点”中添加和排列端口。“管理模板 / 导入”支持编辑、复制及导出单个模板文件，也可将模板导入其他拓扑；导入遇到相同 ID 时生成独立模板，保留原模板。

编辑模板会同步当前图中的引用节点，可一步撤销。删除参数会同时清理其卡片显示项和字段绑定，新增参数需在节点属性中配置绑定；节点自行配置的端口不随模板变化。正在连接的继承端口不能删除或更改类型；修改端口位置时端点跟随，节点坐标和手工拐点保留。

节点属性的“数据绑定”提供参数路径及业务状态映射表单，不必填写 JSON。路径支持 `sensors.voltage` 这样的嵌套字段，留空表示不绑定；状态字段如 `health.state`，可将 `ONLINE`、`0` 等业务值映射为正常、告警、离线。表单配置随 v3 文件保存，独立组件与 HTML 使用相同规则。

## 链路状态与流转

选择连线，在编辑属性中设置初始状态（连通、断开、未知）、流转开关、正向/反向/双向及速度；切换查看模式播放。详情中的模拟断开/连通可快速检查效果，不写入存档。动效沿原有路径播放，保留材质、纹理和拐点；PNG/SVG 是静态快照，HTML 保留动态展示。

独立展示组件的 `setLinkData` / `updateLinkData` 按链路 ID 接收 `up / down / unknown`；连通时 `active: false` 表示空闲。明确离线的端点优先使链路断开；没有链路数据时保持未知。设备数据和链路数据分开更新，宿主需独立提供链路状态，详见 [链路接入说明](docs/integration.md)。组件 `animations: false` 或系统“减少动态效果”可关闭播放。

独立验证页 `/viewer.html` 提供设备与链路两份 JSON；“填入示例数据”同时准备两者，再点击“更新数据”查看流转效果。

## 验证

```bash
bun run test
bun run build
bun run test:e2e
```

数据测试覆盖保存恢复、文件迁移、多图隔离、模板和数据绑定、动态端口、手工走线及非法输入。浏览器主要兼容目标为桌面 Chrome、Safari、Edge 的当前稳定版；测试结果、版本和操作系统记录在迭代指引中。

`bun run test:e2e` 默认运行三个项目，使用本机安装的 Google Chrome、Microsoft Edge 和 Playwright WebKit。浏览器缺失会报错，不会自动用 Chrome 代替 Edge 或跳过检查。先安装 Chrome、Edge，并下载 WebKit：

```bash
bunx --no-install playwright install webkit
bun run test:e2e:chrome
bun run test:e2e:edge
bun run test:e2e:webkit
```

| 目标 | 自动检查 | 实际浏览器补验 |
| --- | --- | --- |
| Chrome | `chrome` 项目，真实 Chrome 稳定版 | 同一套编辑、展示、存储及导出用例 |
| Edge | `edge` 项目，真实 Edge 稳定版 | 同一套用例，不以 Chromium 引擎一致代替验证 |
| Safari | `safari-webkit` 项目，WebKit 全量回归 | macOS Safari 27+ 使用原生接口补验真实绘制和主要流程 |

Playwright 的 WebKit 不是已安装的 Safari 应用，两种结果分别记录。macOS Safari 27 或更新版本可在 Safari「设置 → 开发者」中开启「允许远程自动化和外部代理」，然后运行 `bun run test:safari`。该命令先构建，再通过 Safari 自带的 MCP 接口检查实际浏览器：初始/告警/锁定节点的截图像素、状态与未应用输入、存档、独立组件、SVG、PNG 解码及自包含 HTML 更新。使用临时端口形成独立测试存储，结束后关闭自己创建的标签页，不修改已有站点存档；截图保存在 `test-results/safari/`。

节点绘制位置用例读取截图像素，检查状态色条是否真正绘制在节点坐标处；仅核对 DOM 坐标无法发现 WebKit 中 HTML 节点画到左上角的问题。长标题、零参数、48 端口及常见字体回退也有绘制检查；PNG 除文件头外实际解码并检查内容，SVG 单独打开，HTML 断网验证。

原 `PLAYWRIGHT_BROWSER=webkit`、`PLAYWRIGHT_CHANNEL=chrome/msedge/chromium` 仍可选择单项目；`PLAYWRIGHT_EDGE_EXECUTABLE_PATH` 可指定已解包 Edge 的可执行文件，测试仍运行真实 Edge。标准安装无需设置此路径。

HTML 节点内部保持普通文档流与网格排布；状态色条使用背景绘制，锁定标记使用网格叠放，避免 `foreignObject` 中的相对/绝对定位触发 WebKit 绘制错位。节点位置仍由 X6 管理，修复不修改文件内的布局和拐点。

受限执行环境需允许本地服务监听和浏览器进程；实际测试与部署结果记录在迭代指引中，列举测试命令不代表已经验收通过。

## 代码结构

- `src/document.ts`：通用文档、模板、版本迁移和场景示例。
- `src/library.ts`：多图存储、校验、复制与删除。
- `src/workspace.ts`：自动草稿、历史版本、容量约束、恢复和跨标签页变更检测。
- `src/editor-commands.ts`：复制、粘贴、模板冲突处理、整组位移与批量删除的文档命令。
- `src/layout-commands.ts`、`src/editor-selection.ts`：对齐/分布计算、位置锁定的位移策略及右键选择保护。
- `src/workbench-layout.ts`、`src/workbench.css`、`src/ui-forms.ts`：侧栏布局偏好、制作工具样式及就地表单错误。
- `src/library-presentation.ts`：拓扑库筛选、排序与保留手工布局的轻量缩略图。
- `src/diagram.ts`、`src/diagram-commands.ts`：图面元素校验、分组关系、锁定、成员及层次命令。
- `src/diagram-svg.ts`、`src/diagram-rendering.ts`：图面 SVG 与 X6 渲染，供编辑、展示及导出共用。
- `src/node-status.ts`、`src/node-status-ui.ts`、`src/node-status.css`：共用设备状态外观、动态标记及导出样式。
- `src/workbench-theme.css`：工作台蓝灰主题，与拓扑内容配色分离。
- `src/rendering.ts`：编辑器与组件共用的节点、端口、线缆渲染。
- `src/viewer.ts`、`src/runtime-data.ts`：独立展示组件及宿主字段映射。
- `src/main.ts`：制作工作台、模拟监控与拓扑库界面。
- `src/topology.ts`、`src/port-editor.ts`、`src/cables.ts`：图模型、端口编辑和线缆外观。
- `src/viewer-demo.ts`：独立展示验证页；`src/viewer-index.ts`：组件包入口。
- `src/exports.ts`、`src/export-svg.ts`、`src/export-html.ts`：文件下载、PNG 栅格化、矢量拓扑和离线 HTML 打包。
- `schema/`、`docs/`、`tests/`：格式定义、接入文档和验证。

本次没有接入后端存储、权限或多人协作。独立网页以单文件 HTML 交付，无需额外解压资源包。
